OVERVIEW

Outline Generation + Research --> Stock Media Scraping + Script Writing --> TTS Creation + Verification --> Reference Image Generation + AV Script Creation --> Video Generation + Editing + Video Editor Step --> Rendering / Export

1. Outline Generation + Research
   - Creates outline and does research
   - Review


2. Stock Media Scraping (Optional)
   - Scrapes the Stock Media 
   - Allow media uploads and automatic labeling
   - Review


3. Script writing
   - Creates Script
   - Review


4. TTS Creation + Verification
(TTS WON'T BE CHANGEABLE AFTER THIS STEP UNTIL THE VIDEO EDITING STEP)
   - Script to TTS audio
   - Review


5. Image Reference creation + First Step AV Script Creation
    - Script + Reference Image generation
    - AV Script of general shots
    - Review


6. Second step AV creation + All image, infographic, & Video generations
    - AV Script Generation for specific images, infographics, & videos
    - Image, Infographic, & Video generations
    - Review


7. Automatic Editing + Video Editor Step.
   - Creates LTX-2 Videos
   - Creates Edits
   - Review


8. Rendering / Export
   - Renders video on AWS and gives options for Exporting to YT if connected or downloading
