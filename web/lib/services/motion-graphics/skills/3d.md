# 3D Animation Patterns with Three.js

Use ThreeCanvas from @remotion/three for 3D content. All 3D elements must be inside ThreeCanvas.

## Basic 3D Scene Setup

```tsx
import { ThreeCanvas } from "@remotion/three";
import * as THREE from "three";

<ThreeCanvas
  orthographic={false}
  camera={{
    fov: 75,
    position: [0, 0, 5],
  }}
>
  <ambientLight intensity={0.5} />
  <pointLight position={[10, 10, 10]} />
  {/* 3D content here */}
</ThreeCanvas>;
```

## Rotating Cube

```tsx
const rotation = interpolate(frame, [0, durationInFrames], [0, Math.PI * 2], {
  extrapolateLeft: "clamp",
  extrapolateRight: "clamp",
});

<ThreeCanvas orthographic={false}>
  <ambientLight intensity={0.5} />
  <pointLight position={[10, 10, 10]} />
  <mesh rotation={[rotation * 0.5, rotation, 0]}>
    <boxGeometry args={[2, 2, 2]} />
    <meshStandardMaterial color="#3B82F6" />
  </mesh>
</ThreeCanvas>;
```

## Animated Sphere

```tsx
const scale = spring({
  frame,
  fps,
  config: { damping: 12, stiffness: 80 },
});

const yPosition = Math.sin(frame * 0.05) * 0.5;

<ThreeCanvas>
  <ambientLight intensity={0.6} />
  <directionalLight position={[5, 5, 5]} intensity={1} />
  <mesh position={[0, yPosition, 0]} scale={[scale, scale, scale]}>
    <sphereGeometry args={[1, 32, 32]} />
    <meshStandardMaterial color="#8B5CF6" metalness={0.3} roughness={0.4} />
  </mesh>
</ThreeCanvas>;
```

## Multiple Objects with Stagger

```tsx
const OBJECTS = [
  { position: [-2, 0, 0], color: "#EF4444" },
  { position: [0, 0, 0], color: "#3B82F6" },
  { position: [2, 0, 0], color: "#10B981" },
];

<ThreeCanvas>
  <ambientLight intensity={0.5} />
  <pointLight position={[10, 10, 10]} />
  {OBJECTS.map((obj, i) => {
    const delay = i * 10;
    const scale = spring({
      frame: frame - delay,
      fps,
      config: { damping: 15, stiffness: 100 },
    });

    return (
      <mesh
        key={i}
        position={obj.position}
        scale={[Math.max(0, scale), Math.max(0, scale), Math.max(0, scale)]}
      >
        <boxGeometry args={[1, 1, 1]} />
        <meshStandardMaterial color={obj.color} />
      </mesh>
    );
  })}
</ThreeCanvas>;
```

## Camera Movement

```tsx
const cameraZ = interpolate(frame, [0, 60], [10, 5], {
  extrapolateRight: 'clamp',
});

const cameraRotation = interpolate(frame, [0, durationInFrames], [0, Math.PI * 2]);

<ThreeCanvas
  camera={{
    fov: 75,
    position: [
      Math.sin(cameraRotation) * cameraZ,
      2,
      Math.cos(cameraRotation) * cameraZ
    ],
  }}
>
```

## Wireframe Mode

```tsx
<mesh>
  <torusGeometry args={[1, 0.4, 16, 100]} />
  <meshBasicMaterial color="#3B82F6" wireframe />
</mesh>
```

## Lighting Setup for Product Shots

```tsx
<ThreeCanvas>
  {/* Key light */}
  <directionalLight position={[5, 5, 5]} intensity={1} />
  {/* Fill light */}
  <directionalLight position={[-5, 2, 2]} intensity={0.5} color="#B4D4FF" />
  {/* Rim light */}
  <directionalLight position={[0, -5, -5]} intensity={0.3} />
  {/* Ambient */}
  <ambientLight intensity={0.2} />
</ThreeCanvas>
```

## Ground Plane with Shadow

```tsx
<mesh rotation={[-Math.PI / 2, 0, 0]} position={[0, -1.5, 0]} receiveShadow>
  <planeGeometry args={[20, 20]} />
  <shadowMaterial opacity={0.3} />
</mesh>
```

## Performance Note

Keep polygon counts low for smooth rendering. Use simple geometries when possible:

- `boxGeometry` for cubes
- `sphereGeometry` with lower segments for spheres
- `planeGeometry` for flat surfaces
